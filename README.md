## Dog Sitting Landing Page

A responsive dog-sitting landing page built from the supplied desktop, tablet, and mobile designs.

### Run locally

Open `index.html` directly in a modern browser. No build step or local server is required.

### Implementation

- HTML5 and vanilla CSS only; no framework, preprocessor, or build tooling.
- Uses the supplied imagery and Figma typography: Quicksand (500/700) throughout, with Inter 500 used for desktop and tablet service-card headings.
- Layouts adapt from a three-card desktop grid, through horizontal tablet cards, to stacked mobile cards.

### Design decisions

- The supplied design copy uses “piece of mind”; it is retained to match the design reference, although the conventional English phrase is “peace of mind.”
- The supplied assets do not include a standalone arrow icon, so the links use a text chevron.

### AI assistance

AI was used to help structure and refine the HTML/CSS. The output was reviewed and adjusted against the supplied design tokens, responsive requirements, semantic structure, and accessibility basics.
